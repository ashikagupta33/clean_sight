# CleanSight ML Module
- inference.py: YOLOv8s litter detection inference script (supports image & video).
- MLPro2.ipynb: Training notebook on TACO dataset (4 classes).
- Model weights: `best.onnx` is committed at `backend/models/best.onnx` and is what the backend serves. `best.pt` is shared separately and is needed only for retraining or for `inference.py`.
